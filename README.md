## Selected projects

### [ST Card Editor](https://github.com/maxime-fleury/ST-cardEditor)

A studio for editing, translating and enhancing SillyTavern character cards. It brings together a card library, AI-assisted editing, search, version history and multilingual support.

[Try the demo](https://maxime-fleury.github.io/ST-cardEditor/) · [Browse the code](https://github.com/maxime-fleury/ST-cardEditor)

### [Launcher](https://github.com/maxime-fleury/Launcher)

I built so many apps that I needed an app to launch them. Bun Launcher is an Electron desktop app that discovers my Bun projects, starts and stops them, handles ports and brings their logs into one place.

[See the interface and README](https://github.com/maxime-fleury/Launcher#screenshot)

### [CronDash](https://github.com/maxime-fleury/CronDash)

A dashboard for Windows Scheduled Tasks. I wanted to pick a script, choose when it runs and keep track of the result. One everyday use: regularly cleaning up old, unneeded files in my Downloads folder.

Built with Bun, JavaScript and Bootstrap, with task management, a PowerShell script editor, logs and activity statistics.

### [AI News Radio](https://github.com/maxime-fleury/AINewsRadio)

A fun experiment with a personalised, continuous news radio. It gathers news, turns it into a spoken show and lets me interact with it by asking questions or choosing topics, with a synchronised transcript and replay.
